# Library Management System

A console-based library management system developed in **Java 17**, focused on Object-Oriented Programming, Clean Code, and software engineering principles.

---

## About the Project

The **Library Management System** is a project developed to practice software engineering concepts through the development of a real-world application.

The system is designed to manage the main operations of a library, including:

- Books
- Readers
- Loans
- Returns
- Fines
- Book availability

The project is being developed with a focus on **Object-Oriented Programming (OOP)** and **separation of responsibilities**.

---

## Features

- [ ] Register books
- [ ] Search books
- [ ] List available books
- [ ] Register readers
- [ ] Search readers
- [ ] Borrow books
- [ ] Return books
- [ ] Track active loans
- [ ] Calculate fines
- [ ] Control book availability
- [ ] Store data persistently
- [ ] Multilingual terminal interface
